## 🎯 怎么用

1. **按名字找**：在 xlsx 里 `Ctrl+F` 搜符号名（比如「肖特基」），预览列直接看图，不用一个个点开。
2. **要矢量图**：点「SVG 矢量图」列的链接，浏览器直接打开，`Ctrl+S` 存下来；也可以右键另存。
3. **塞进文档 / 讲义 / 原理图**：SVG 拖进 Word、PowerPoint、Inkscape、Figma，或 KiCad 的原理图编辑器都能用。矢量图放大到 A0 也不糊。

每个分类一张工作表，前四列固定：

## 它是什么 / 不是什么

| 是 | 不是 |
| --- | --- |
| 图形符号素材（原理图上画的那个记号） | KiCad `.kicad_sym`、Altium `.SchLib` 那样的**元件库文件** |
| 可无损缩放的 SVG + 内嵌预览的索引表 | 封装库、引脚定义、3D 模型 |
| 按类整理、编号连续的速查表 | 电气参数手册（没有耐压、电流这些数值） |

要直接进 EDA 画图，还得把这些 SVG 导成对应软件的库符号；当素材、当讲义插图、当速查表，开箱即用。

## 🔧 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 双击打不开 | `.xlsx` 需要 Excel / WPS / LibreOffice；不是改后缀就能当文本看的压缩包 |
| 预览列空白 | 图片是**内嵌**的，某些手机只读预览器不渲染内嵌图，换桌面端打开 |
| SVG 点开一片白 | 正常——矢量图没有背景色；存下来拖进编辑器或图片查看器就能看到 |
| 找不到某个符号 | 先按分类找；同类不同画法基本都收了（例如二极管的实心与空心） |

## 为什么是 SVG + 内嵌预览

图纸上的符号最终会出现在三种地方：文档插图、讲义 PPT、原理图编辑器。位图在第三种地方最先崩——缩小看不清引脚、放大全是锯齿。SVG 是唯一能同时满足「任意缩放」「体积小（4–6 KB）」「能改线条颜色」的格式。

预览图则解决另一个问题：符号名是中文长名（「肖特基二极管（实心）」），光看文字对不上图形。把 JPG 直接嵌进单元格，翻表时眼睛扫过去就能确认，不用点开每个链接。

## 编号与分类怎么定的

- **分类按器件家族**，不按字母、不按复杂度：二极管、晶体管、逻辑模块、电源与连接器……找东西时人的第一反应是「这是个什么器件」，不是一个字母。
- **编号全表连续**：这样跨类引用也只有一个数字（「第 117 号」），不用写「逻辑模块第 31 个」。
- **同类不同画法并列收录**：实心 / 空心、矩形 / 折线，这些是不同标准下的画法，不是同一样东西的重复，所以都留。

## 怎么往里补新符号

1. 先定它属于哪个家族，找不到合适的类再开新表；
2. 编号取当前最大值 + 1（不要按类重新从 1 开始，会破坏跨类唯一的性质）；
3. 传一份 SVG 到图床对应分类目录，再把链接填进「SVG 矢量图」列；
4. 预览图嵌进单元格，顺手在文件开头的统计行改掉「共 N 个符号」。
