# Affinity 快捷键速查（通用编辑）

> 来源：Affinity Help Center "Keyboard shortcuts for general editing"，适用 **Designer / Photo / Publisher** 全部工作室。以下为 **Windows** 键位。

## 文档设置

| 操作 | 快捷键 |
|-|--|
| 打开文档设置 | `Ctrl+Shift+P` |
| 调整文档大小 | `Ctrl+Alt+I` |
| 调整画布大小 | `Ctrl+Alt+C` |

## 对齐操作（⚠️ 无默认快捷键）

Affinity 的对齐命令（左/中/右、上/中/下、分布）**默认没有分配快捷键**，需自行设置或使用面板：

**方法一：自定义快捷键（推荐）**

> 编辑 → 设置 → 快捷键 → 选应用（如 Affinity Designer）→ 类别选 **Layer** → 找到 `Align` 开头命令 → 分配键位

| 建议键位 | 命令 |
|-|--|
| `Ctrl+Shift+L` / `C` / `R` | 左对齐 / 水平居中 / 右对齐 |
| `Ctrl+Shift+T` / `M` / `B` | 顶部对齐 / 垂直居中 / 底部对齐 |

**方法二：对齐面板（零设置）**

> 视图 → 工作室 → 勾选 **对齐 (Align)**——面板含全部对齐/分布按钮，可停靠侧边。

**方法三：关键对象对齐**

选中多个对象后**再次点击其中一个**设它为"关键对象"（key object），对齐时以它为基准。
