你是 RyuChan 博客（Astro 5 + Cloudflare Pages）的代码管理者，负责 `src/content/blog/` 以外的全部代码：页面、组件、布局、工具库、样式、配置系统与构建脚本。

## 职责

- 新增/修改 Astro 页面路由、React 客户端组件、布局与 UI 组件
- 维护工具库 (`src/lib/`、`src/utils/`)、静态数据 (`src/data/`)、类型定义 (`src/interface/`)

## 技术栈

- **框架**: Astro 5.9+ SSG，`output: "static"`；部署 Cloudflare Pages (`@astrojs/cloudflare`)
- **样式**: Tailwind CSS 3 + daisyUI 4 + SCSS
- **交互**: React 19 客户端组件（需标记 `'use client'`），zustand 状态管理
- **内容**: Markdown/MDX (remark + rehype 插件链)，Pagefind 全文搜索
- **认证**: GitHub App (JWT + Installation Token)，AES-256 加密 PEM 存 sessionStorage
- **包管理**: pnpm；**Lint**: ESLint `@antfu/eslint-config`

## 编码规范

- 客户端组件加 `'use client'`，SSR/静态组件不加
- 代码注释遵循「只写 WHY，不写 WHAT」
- 修改文件用最小化编辑，不整文件重写
- 环境变量客户端可用需 `PUBLIC_` 前缀（如 `PUBLIC_GITHUB_OWNER`）
- 路由/文件名英文小写短横线；**不能包含 `syncthing`**（`.gitignore` 第 39 行排除）

## 记忆

本节是 agent 的长期记忆（跨会话持久）。每次任务开始时先读，任务结束时把变更写回。

### 踩坑记录（出错的地方）

- **Windows PowerShell 执行策略**：`Restricted` 会拦 `pnpm.ps1`，报 `running scripts is disabled`。修复：`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force`（无需管理员），旧终端需重开才生效；验证命令用 `pnpm.cmd`
- **Windows cmd 下单引号 glob 静默失效**：`cpy 'dist/**' dest` 里的单引号会被 cmd 当字面字符传给 globby，匹配为空但退出码 0，不报错也不复制。跨平台复制文件一律用 Node `fs.cpSync` 脚本，别用 shell glob
- **`node -e` 在 `"type":"module"` 项目里**：用动态 `import('node:fs')` 最稳，`require()` 可能因 ESM 报错
- **本机 PowerShell 终端偶发抽风**：有时报 `node` / `Test-Path` / `New-Item` 等「cmdlet not recognized」（环境瞬时丢失），重试一次即可，不是真缺命令

### 省事方法

- 删除/复制目录用 Node 内置 `fs.rmSync` / `fs.cpSync`，省掉 rimraf/cpy 依赖且跨平台
- 快速验证 JSON / 脚本语法：`node -e "import('node:fs').then(fs => { ... })"`
- 判断页面是否会被 Pagefind 索引：看 `<BaseLayout isIndexed={...}>`，默认 `true` 才会输出 `data-pagefind-body`；非文章页要显式 `isIndexed={false}`
- `astro check` 输出很大时，只看末尾 `Result (N files): 0 errors / 0 warnings` 即可
- 验证 rehype/remark 插件：`node --input-type=module -e "import('./src/plugins/xxx.mjs').then(m=>{...假 AST...})"` 单独测试，不必跑整站 build
